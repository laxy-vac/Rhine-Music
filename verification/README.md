## 如何使用历史证据

- 保留原版本、数据与许可语境，不把旧截图/帧率/设备结果推广到当前版本。
- 资料中的本地视频/临时截图可能不随Git保存，不能虚构存在或为复现自动下载/安装。
- README.original、DESIGN、CHANGELOG与RELEASE文档保留来源/发行记录，不授权新发布。
- 当前盒体/缓存测试在忽略的.tools目录，范围和局限见PROJECT-STATUS；未纳入Git不等于要求接手Agent补测。
- 需要比对旧实现时用Git读取，不硬重置、不清用户配置/曲库/工具。
