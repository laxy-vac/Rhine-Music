## 三项结构性优化（2026-10-19 已完成）

按用户要求逐项实施：四种日夜交互都达到平均 120 FPS 才提前停止，否则完成三项。本轮三项均完成，最终未达到该目标。保持极致档、Punk 拓展盒型、现有材质参数、原主光方向、分辨率与动效；未安装工具或变更依赖、系统配置。

1. **封面按内容驻留。** 有界内容 key→图块映射把逻辑槽位与纹理位置分开；命中只改 UV，未命中才绘制/上传。选中和退回副本共享引用计数保护的原 1024px 纹理，满缓存且全被引用时回退独立副本。异步解码、fallback 标题、独立淘汰与外部采样设置保留。
2. **颜色、阴影使用各自的实例列表。** 逻辑池与 hitProxy 不变，渲染时按保守包围盒和相机裁剪，单独阴影副本保留视窗外投影者；矩阵、UV、标签、徽标和 hi-res 属性一起打包，结束或异常均恢复。AO 与景深共享深度；直接使用原生深度会改变旧景深，已拒绝该版本。最终模拟原 RGBA16F 打包舍入，夜间点/线补入深度；详情、转场及尺寸不匹配档位回退原深度路径。
3. **ARRAY 派生视觉更新与文字缓存。** 每个输入立即推进逻辑索引与 entry key，同一显示帧只提交最终视觉目标；异轴、开返、库替换和页面边界先消费待提交目标。沿既有帧处理文字与标题待排布局，保持动画开始帧。artist/meta 使用各自 128 项精确 fit 缓存，按字体、CJK、宽度、样式失效；滚字库及其内部字形测量未修改。隐藏详情留到原 prepareMenu 在开盒前构建，播放仍按即时逻辑选择执行。

## 主场景瓶颈与当前追加优化

用户将本阶段调整为总计 20 轮实验与复测，帧生成暂缓。四种日夜交互的真实平均渲染均达到 120 FPS 才算达标；达标后仍继续验证其余候选方向，保留经复测有效且不影响画面与设置的组合。参考材料用于提出假设，不以它代替本项目的测量证据。保留所有盒体设置、极致/Punk、原主光方向与动效。

第 1 轮在主场景分项计时中定位到 ARRAY 退场标签首次纹理上传，约 13.33ms/采样帧；这项成本原先被计入透射捕获的最后一个标签绘制，不能归因于玻璃着色器。改为容量 16 的打印编号/资源 generation 驻留，选中与退场各自持有引用；保留 1024px、原像素、采样与独立材质，满缓存且全被引用时回退原私有纹理。资源刷新不改变尚在显示的退场快照。

优化后 ARRAY 分项采样中未再出现标签上传；透射不透明绘制约 2.54ms、主不透明绘制 1.47ms、阴影 0.77ms、玻璃正绘 0.59ms、背面 0.46ms、透射 resolve/mipmap 合计 0.49ms。标签与设置回归通过，10 项盒体设置的整窗差异最多 1 个色阶。但交替开关的 ARRAY 帧率仍有明显波动，未证明稳定的平均 FPS 改善，也未达到 120 FPS。暂停场景绘制时调度约 175–180 FPS，仅说明显示调度具备超过 120 的空间。

CPU 采样随后发现重复实例矩阵写入约占 14%。第 2 轮共享逻辑变换数据，几何、材质、UV、部件设置及命中池保持独立语义。单组有效的同进程 6 秒前后样本中，日间 ARRAY 46.88→64.89 FPS、夜间 41.36→59.33 FPS；MATRIX 约 60 FPS 持平。标签和盒体设置像素回归通过；约 2500 帧连续操作中，11692 次可见资源检查未发现纹理缺失、提前释放或退场封面身份改变。有限检查不代替用户观察，也不证明所有场景绝无闪烁。第 3 轮继续处理同帧 DOM 测量与文字更新引起的同步布局等待。

20 轮是上限，有价值方向耗尽可以提前结束。当前结果与局限见 [performance-main-render-20261019.json](performance-main-render-20261019.json)，原始采样及有限回归保存在本机忽略目录 `.tools/performance-main-render-20261019/`。探针中断、验证夹具问题与有效采样分开记录，不能把整次失败试跑称为通过。隔离合成输入采用 CDP 定向浏览器事件；限定在画布内的拖动在夹具中绕过 Windows 物理按键不匹配导致的捕获撤销，生产输入代码未改变，两种对照一致。最终组合仍需同条件累计复测。

第 3 轮在逐帧业务文字写入前读取这一帧的视窗尺寸，并在同一同步帧中复用；微任务结束即失效，resize/布局切换立即清除，不跨帧冻结几何。成对样本中 ARRAY 日间 57.33→59.28 FPS、夜间 61.11→64.40 FPS，MATRIX 仍约 60。带诊断的 CPU 采样中，视窗测量自身时间按实际捕获帧归一后约 3.24→1.14ms/帧；这与未插桩 FPS 样本分开报告。1920×1080 与 2560×1440 尺寸回归、标签/盒体设置对照及连续可见资源检查通过。

第 4 轮为隔离诊断，不作为生产优化交付：同一场景/材质/动效下冻结外围 UI 与元数据提交，ARRAY 日间 58.94→95.01 FPS、夜间 40.57→86.16 FPS，MATRIX 约 60 不变。主场景 GPU 分项合计日间约 10.96ms、夜间约 11.15ms，已经超过 120 FPS 的 8.33ms，且尚未包含其他后处理。后续同时关注 MATRIX 的不透明/玻璃多次覆盖与 ARRAY 的 UI/场景调度。Worker 具有 ARRAY 隔离价值，但不能单独解决 MATRIX 的 GPU 预算；完整迁移还涉及 DOM、字体、Canvas、命中和玻璃叠层的线程边界。Three 0.183.2 的现有 GLSL/onBeforeCompile/EffectComposer 不能直接替换为 WebGPURenderer，暂不以更换后端替代这些已确认热点。

第 5 轮近处优先不透明提交已撤回：默认 MATRIX 静态比对零差异，但设置回归仍有少量像素差异；ARRAY 初版也出现光学边缘差异。MATRIX 约 2–4% 收益不足以抵消潜在闪点的不确定性。第 6 轮同一 RAF 后置 Rhine ARRAY 派生 DOM 提交的工作流/开返回归通过，但 ARRAY 日间 69.49→63.53 FPS、夜间 71.96→67.22 FPS，亦撤回。两轮失败分支及数据保存在隔离目录，生产保持前三项已验证增益；继续验证着色程序复用与完整效果 Worker 原型，不把“改变调用顺序”直接当作提速。

第 7 轮 ARRAY 相同着色程序复用亦已撤回：日间 69.18→71.82 FPS、夜间 63.53→73.01 FPS，MATRIX 约 70 FPS 持平；四种默认画面像素相同，2690 帧中 12950 次资源检查通过，连续切选/开返身份正确。但单独开关这一项后，10 项设置中部分透明/磨砂组合的少量像素最大差 28，未通过最大差 1 的严格条件。尚未证明存在肉眼闪烁，也不能将这项差异当作已验收；生产撤回，保留失败数据。

| 闲置与页面生命周期 | 共用场景与资源已有释放路径，实际闲置开销未测 | 静止、隐藏、页面切换及开返后的持续更新、监听器、纹理重画/上传和内存增长 |

音频 DSP 实时优化、Punk UI 大修及其他入场不属于本阶段，除非用户另行指定。

## 测量口径

记录同一主题/日夜、布局、盒型/材质、画质档位、实际渲染尺寸/DPR、窗口比例、显示状态、数据规模、缓存和运行环境。优先用可重复的合成目录及 mock 音频隔离问题；个人曲库和真实设备只在获准范围内使用。

覆盖静止、选片、MATRIX 拖动、ARRAY/MATRIX 切换、详情开返、页面切换、歌词/信号页等实际操作。按发现的问题选取代表场景，不要求每次穷举全部组合。

帧时间来自实际 RAF/性能时间戳或可靠的 CPU/GPU 观测。`src/scene.ts` 当前 `stats().frameTime` 返回 `this.clock`，是场景累计时间；`drawCalls/triangles` 直接来自 `renderer.info.render`，尚未建立整帧多 pass 汇总口径。不要直接把这些字段当成完整帧成本。GPU 时间不可用时明确说明，不能由 CPU 时间倒推。

`quality-detection.ts` / `quality-benchmark-frame.ts` 已有合成 ARRAY 和开返场景、FPS、P95、慢帧比例及样本数，可按需要复用。它用于画质建议，不覆盖所有布局或真实曲库，也不是当前 RTX 5080 的瓶颈结论。

## 需要保护的实现

- Future/Punk 共用状态、目录、播放、ArchiveScene/WebGL 和生命周期，不复制第二套权威状态或 renderer。
- 公共布局值仍是 `shelf`→ARRAY、`array`→MATRIX、`grid`→GRID，entry key 与父专辑身份不能被槽位编号替代。
- ARRAY 每架 20 槽；普通 MATRIX 池为 9×48，桥接预留 729 槽。已有可见专辑保持身份，循环副本、末列与地下裁剪规则保留。
- 只优化桥接实现时仍保留原静态镜头：MATRIX 距离 140、基准 span 7.33、59°/25°；不能根据 ARRAY 缩放或实例数改变 MATRIX 构图。ARRAY 保留自己的响应式镜头规则。
- 渲染链包含主场景、SSAO、Bokeh、SMAA、播放栏玻璃/输出与阵列淡化等 pass，启用情况受画质影响。Punk 源盒体为 98,080 三角形、15 部件类型；这些是候选成本，尚未证明是掉帧原因。
- 不通过降低用户画质、切换盒型/设备、清个人缓存、缩减条目或改变偏好掩盖问题。诊断时临时对照参数须明确记录并恢复。
- 源模型、材质与视觉资源的版权、哈希版本、用户预设和数据格式保持；原生音频输出与设备释放不可因图形优化退化。
