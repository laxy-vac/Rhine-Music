# Sony音效桥接

Windows播放器提供DSEE AI、DC相位线性器和黑胶处理器。三项算法由Sony原ARM指令转写并编译为x86-64 C++，使用原模型和参数；原ARM参考路径保留用于软件对照。

## 来源与归属

DSEE AI取自Sony官方DMP-Z1 1.02固件，包含DseeAi、DSX 3.0.7、60000字节模型及ICX1291配置；相位器与黑胶来自同一音频库，原初始化参数和CSV预设保留。固件仅作来源解包，不运行刷写程序。

九个原始运行文件的固定SHA-256见[assets.json](../scripts/sony-walkman/assets.json)，原文件在`vendor/sony-walkman`。算法、模型、参数及相关派生代码不改授项目MIT，Sony及商标归属见[NOTICE](../NOTICE.md)。

软件桥接不等于复刻整台Walkman的解码、路由、音量、S-Master放大器或DAC。它处理解码后的浮点PCM，当前串接顺序为AI→相位器→黑胶。

## 处理契约

- 左右声道各有独立原上下文，再按原位模式交错回双声道；滤波状态、系数和运算顺序保持，不把两声道送入同一历史。
- DSEE接受44.1/48kHz单/双声道PCM，输出176.4/192kHz；相位器与黑胶接受44.1、48、176.4、192kHz并保持输入率。
- 高采样率输入只执行支持该率的已启用效果，不为使用DSEE静默降率；界面显示实际生效或旁路原因。
- 原生DSD/DoP不进入Sony PCM链路；转PCM后才可处理。当前输出及DSD路线以[音频实现](AUDIO-CORE-IMPLEMENTATION.md)和[DSD](DSD-PLAYBACK.md)为准。
- 原版模块输入/输出为Float32；转回double缓冲不能恢复其内部已丢精度，不显示无法确认的内部运算位宽。

## 并行与实时供应

音效默认关闭，多核与边算边播设置默认开启。每项效果保持一条连续状态；多项启用时最多三个工作进程，资源较少时合并阶段，不按独立音频碎片拆分滤波或神经网络状态。

Windows从原生解码管道供应PCM，切换效果以当前可听位置重开并取消过时任务，保留歌曲时间轴。设备回调不等待尚未生成的数据；CPU供给不足时明确显示缓冲状态。关闭边算边播时仍按既有完整准备流程工作。

限定片段的串行/并行及原ARM/x86对照只说明该输入范围内的软件行为，参考输出方法见[测量说明](SONY-AUDIO-MEASUREMENTS.md)。它们不是当前整机实时性能基线，后续按[优化基线](OPTIMIZATION-BASELINE.md)测量。

## 本地组件与构建

复用已准备的项目内Sony文件、x86运行库、解码组件及Zig工具，清单/指纹由构建与启动校验。准备或更换Python、Unicorn、编译器、运行库及任何依赖须先获用户授权，普通入口不下载安装或修改全局PATH。

转写代码、生成器、地址/指令元数据和构建说明见[native/sony](../native/sony/README.md)。未知地址或无效访问明确失败，不静默回退到另一实现或放宽固定组件检查。

## 音乐来源

本地和已缓存到本机的FTP曲目使用同一处理链。FTP/FTPS由用户在设置配置和主动扫描，只读远端；不支持SFTP，不改写远端标签。曲目完整下载到本机缓存后读取真实元数据并播放，FTPS校验证书。

连接凭据仅保存在数据目录的`ftp-library/connection.json`，不进入源码或浏览器状态。FTP单曲缓存上限1GB、总容量4GB，用户可主动清理；数据位置见[本地开发](LOCAL-DEVELOPMENT.md)。

实际输出、设备精确率支持、回调稳定性和DAC行为须独立验证，不能从软件对照或界面截图推断。
