# 界面语言与频谱优化

2026-10-11。仅必要 TypeScript/Vite 构建与源码审阅，未运行播放器、个人音乐、音频设备、自动化交互或截图验收。

## 使用

设置 → 外观与显示 → 界面语言，可选简体中文和 English，点击“应用语言”后重新载入界面并返回当前设置分类。桌面版复用既有原生会话恢复流程；浏览器播放会随页面重新载入而停止。本轮没有实测重载/恢复，因此不把会话恢复写成已验收结果。

语言偏好保存到现有本机 `preferences.json` 的 `language` 字段，并同步渲染器语言存储。没有语言值的旧配置默认中文，字段仅允许 `zh-CN / en`；没有迁移、删除或改写音乐、歌词或预设数据。桌面 preload 在界面模块初始化前恢复语言，避免本地服务端口变化后丢失选择。

中文模式保留 RHINE LAB、MUSIC ARCHIVE、页面英文眉题、SYSTEM NOTICE、3D/2D/CLASSIC/SPECTRUM 等装饰和模式名。按钮、设置名称、用途说明、状态、无障碍标签与单位说明按界面语言显示。

覆盖音乐终端导航、音乐库/搜索/在线界面、设置、EQ/音调、歌词与服务器管理、音频信息、播放条、信号、画质/模型查看及相关提示。已知问题与选择音乐/歌词缓存文件夹的系统对话框也接收显式语言值，保留 IPC 窗口归属校验。

## 本地化边界

`src/i18n.ts` 的 `trUi()` 只用于应用自带字面量；`ui` 模板标签在插入动态值之前翻译静态片段，按 HTML 属性上下文转义译文。英文词表分别为 `src/i18n-main-en.ts` 与 `src/i18n-panels-en.ts`，中文原文为查找键。

曲名、专辑/歌手、流派、歌词/翻译歌词、制作人员、资料正文、路径、设备/驱动名和用户输入保持原文。保存/导入的 EQ 预设名、自定义歌词服务器名保持原样。内置网易云/QQ 只按稳定源 ID 显示英文品牌名，不修改共享服务器或缓存记录。未知后端或第三方的原始诊断保留原文，词表没有包含的应用短语回退到原文，不隐藏错误。

模式值、配置键、设备 ID、处理参数与 JSON 内容不翻译。`localNote` 中的 `授权：` 继续作为原格式的数据解析前缀。纯输出校验新增 `pcmConsistencyCode()` 的 `pending / match / mismatch` 稳定状态，显示文字与颜色判断分开。

后续新增可见文案应接入同一词表，不对 DOM 或曲库做自动翻译；维护跨插值片段时应检查英文顺序、空格和数值单位。原版历史档案入口、外部网页/资料与第三方诊断不在本轮英语重写范围。

## 频谱

源码确认旧原生状态轮询约 4 Hz，且同一 FFT 被反复计算对数坐标、重建网格与绘制。此次改为前台信号页按需约 10 Hz 轮询，缓存静态网格/坐标/像素桶，只有新数据才聚合；单一 RAF 绘制与真实快照之间的显示平滑，读数仍来自原始 bin。后台/离页释放临时需求，C++ 回调、音乐处理与输出未修改。详见 [SIGNAL-PAGE.md](SIGNAL-PAGE.md)。没有设备或实际帧率测量，流畅度由用户验收。
