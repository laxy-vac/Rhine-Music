**历史实现记录（2026-10-10）：** 当时QQ使用smartbox搜索，网易云/QQ以曲名和歌手检索、多源请求分别回报成功/无匹配/错误，并由用户选择候选。旧公开演示查询和隔离mock只代表当时接口样例与手动流程；它们不验证当前自动匹配、当前平台状态或所有曲目。接口和内容供应仍可能变化。

## 使用

全局配置位于设置 → 歌词：选择默认来源、共享服务器与歌词缓存目录。中央歌词标题区仅保留一个无文字小图标，打开“歌词选项”弹窗；查找、导入、本曲来源与歌词偏移都在弹窗中。单曲来源可跟随全局或指定共享来源，临时检索选源不修改保存偏好。新设置默认QQ；旧version 1配置若默认来源为网易云，会在内存中切换到QQ并在下次保存时写为version 2。version 2、自定义全局来源和单曲显式来源保留。

顶栏“歌词”与音乐库、EQ平级。左侧播放信息可独立滚动，底部频谱固定保留完整高度；中央阅读歌词，右侧只保留封面与曲目信息。歌词选项弹窗分“查找歌词”和“本曲设置”，来源管理跳到全局设置。Esc关闭弹窗，不切换页面；音乐继续播放。

1. 播放器识别当前曲目后立即后台解析歌词，即使歌词页没有打开也会开始。服务先读取本机缓存；命中时直接显示，不联网。缓存未命中时才自动检索来源，默认优先QQ。请求按当前有效来源（单曲显式来源或全局默认）优先，随后QQ，再尝试其他启用来源；新配置的全局默认是QQ。单曲显式来源和用户保存的全局自定义来源仍优先于默认。全流程最多20秒。
2. 自动匹配只会采用可信度足够的版本：先核对归一化后的精确曲名；艺人信息可用时还需匹配艺人，艺人未知时再用专辑或时长辅助。每个来源最多尝试三个匹配候选；来源错误、歌词为空或候选不可靠时继续下一个来源。区分“未找到可靠匹配”和“来源暂时不可用”，歌词页提供“重新匹配”按钮。平台数据和网络状态仍可能导致没有可用歌词，不能保证每首歌曲都能取得歌词。
3. 手动查找仍可从小图标弹窗使用：打开弹窗本身不会另发手动搜索；点击“搜索”或在查询框按Enter后，显示分来源状态和候选。点选候选会取得并保存该版本，手动查找或选择优先于正在进行的自动匹配，自动请求的迟到结果不能覆盖手动结果。离开歌词页会取消手动界面请求，但当前曲目的自动解析继续；切换曲目后，旧曲结果不会替换新曲显示。
4. 每曲只保留一个本机歌词缓存文档，按曲目ID的SHA-256命名，包含原文、可用翻译、来源和偏移。新文档为version 2，用户偏移写入LRC的`[offset]`标签，`offsetMs`只记录相对原歌词的用户调整量；播放同步和点击定位不会重复应用偏移。旧version 1歌词缓存继续读取，显式替换歌词或保存偏移时才升级为version 2。偏移范围为±30秒，正值表示提前。
5. 也可导入UTF-8 LRC/TXT（最多96KiB）。界面将文件完整内容作为UTF-8文本副本发送给本机服务；API只接受歌词文本，不接受或接收原文件路径。源文件及音乐文件都不会被修改或删除。纯文本只阅读，不模拟时间轴；暂不处理平台加密逐字歌词。点击有时间的行定位歌曲。
6. 跟随播放默认开启，并在切歌和返回歌词页时重新启用。用户滚轮、触摸、拖动滚动条或歌词区滚动按键会暂时关闭跟随；程序自动滚动不会关闭。手动滚动后可勾选“跟随播放”或按“回到当前行”恢复。原LRC中的有效整数`[offset]`也按正值提前解析；保存偏移后弹窗保持打开。无歌词时偏移控件禁用，歌词正文不外露这些控件。

## 来源适配与本机数据

`scripts/lyrics-library.mjs`独立负责搜索、自动可靠匹配、候选、歌词获取与保存。网易云和QQ分别适配，没有下载或加载foobar插件二进制。自动解析逐源尝试，单个来源错误不会阻止后续来源；自动请求总时限20秒。手动`sourceId=auto`仍并行查询已启用来源并分别回报来源状态，候选按真实来源缓存，选用时不会把auto误作服务器ID。全局默认来源、单曲来源覆盖和自定义源配置分别保存；version 1的网易云全局默认在内存中转为QQ，显式version 2、自定义全局来源和单曲来源不迁移。来源错误、验证页、HTTP错误与空候选分别回报，不使用代理、登录Cookie或伪造地域标头。

歌词缓存默认位于`MUSIC_DATA_DIR/lyrics/cache/<trackId的SHA-256>.json`；可通过Windows文件夹选择器指定缓存目录。更换目录本身不搬运缓存。读取按当前目录、最多16个配置历史目录、默认目录回退。显式替换歌词或保存偏移时，服务会验证当前/历史/默认目录中同一曲目的旧播放器缓存，将新文档写入当前目录并清理已验证的旧副本；不扫描其他曲目或配置目录之外的路径。未知、损坏、非普通文件或符号链接会保留，并拒绝覆盖，以保护无法确认用途的数据。正常完成后配置范围内每曲只保留当前文档；文件系统写入/删除失败会返回错误。偏移保存前还会再次比对刚读取的歌词文档；若它期间已被替换，就拒绝应用旧偏移，避免覆盖新选用的版本。全局默认源/目录在`MUSIC_DATA_DIR/lyrics/settings.json`，共享自定义来源在`MUSIC_DATA_DIR/lyrics/sources.json`，单曲来源覆盖在`MUSIC_DATA_DIR/lyrics/track-preferences/<hash>.json`；缓存目录变化不改动单曲偏好。删除共享服务器后，引用它的曲目暂用全局来源并显示来源失效；原覆盖保留，用户可选新来源或恢复跟随。

这些本机数据不进入Git，不写音频标签。歌词内容只留本机。损坏的缓存/配置会报告错误并保留文件；正常写入使用串行原子替换。歌词解析请求绑定当前曲目，过期结果不能覆盖新曲显示。离页只停止手动界面请求；自动当前曲目解析继续。

自定义源支持HTTPS JSON GET接口，本机localhost/127.0.0.1/::1服务可用HTTP。默认搜索响应形如：

```json
{"results":[{"id":"song-id","title":"歌名","artist":"歌手","album":"专辑","duration":240}]}
```

歌词响应形如：

```json
{"lrc":"[00:01.00]歌词内容","translation":"[00:01.00]翻译内容"}
```

URL模板支持`{query}`、`{title}`、`{artist}`、`{album}`、`{id}`，各值独立URL编码。高级映射可指定点分字段路径，例如`{"results":"data.songs","id":"mid","title":"name","artist":"singer","album":"album.name","lrc":"data.lrc","translation":"data.translation"}`。艺人可为文本或带name的数组，时长按秒。最大12个自定义源；不执行用户脚本，不从候选中的任意地址下载文件。

## 频谱来自哪里

- WASAPI/ASIO PCM：`native/pcm-spectrum.h`收集真实PCM，在DSP、SRC和队列混音之后、主音量/淡变/量化之前取样。实时回调仅复制固定容量原子环形缓冲，FFT在status线程最多每100ms计算一次；不修改音乐样本。切曲/定位/暂停/停止重置历史，切轨或环形窗口覆盖时丢弃分析结果。
- 显示使用32个对数频段，范围20Hz至min(20kHz,Nyquist)，左右声道取较大能量，映射约-72至0dBFS。FFT窗口随采样率在4096至32768帧之间选择。这是视觉近似，不是精密频谱测量；取样精度不属于音乐输出处理精度链路。
- 浏览器兼容播放：歌词页可见时才接入当前歌曲的Web Audio Analyser，8192点FFT、32个对数频段；使用真实当前歌曲数据。分析不包含独立BGM或界面音效。
- 原生DSD/DoP直出暂无PCM频谱，不把DSD载荷或DoP容器当成音乐PCM分析；页面明确显示不可用。歌词进度仍可同步。

## foobar2000参考与接口资料

参考[foobar官方OpenLyrics页面](https://www.foobar2000.org/components/view/foo_openlyrics)及维护者的[来源适配器目录](https://github.com/jacquesh/foo_openlyrics/tree/main/src/sources)：采用独立来源、本地优先与可取消请求。当前自动解析按来源顺序尝试并只采用可靠匹配；手动多源搜索仍用于用户查找和覆盖选择。自动联网只在识别当前曲目且本机缓存未命中后发生；手动搜索仍需用户点击。页面离开不取消当前曲目的自动解析。没有复制C++实现或加载其插件ABI。

协议参考OpenLyrics的[网易](https://github.com/jacquesh/foo_openlyrics/blob/main/src/sources/netease.cpp)和[QQ](https://github.com/jacquesh/foo_openlyrics/blob/main/src/sources/qqmusic.cpp)适配器。2026-10-10公开演示“晴天 / 周杰伦”检查中，旧QQ Desktop POST返回服务码2001；smartbox HTTPS GET返回歌曲mid，既有歌词HTTPS GET返回retcode=0及非空定时歌词。网易云GET也返回code=200和可解析候选。这些是当时样例健康结果，不保证所有歌曲/地区或平台接口长期可用，不将无法访问当作“没有歌词”。

来源接口与歌词内容保留各自权利，不改授本项目MIT；歌词缓存只留本机，不分发歌词内容。
