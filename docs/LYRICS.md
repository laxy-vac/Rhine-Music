2026-10-10。本地实现。已针对窗口布局与来源检索修复：QQ更换为公开可用的smartbox搜索；网易云/QQ的请求词使用曲名与歌手，专辑只用于区分候选；多来源检索分别回报成功、无匹配与错误。公开演示查询核实了QQ搜索和定时歌词接口；隔离mock覆盖来源、缓存选择与取消。没有读取个人音乐或操作音频设备。具体曲目及平台接口仍可能受内容供应/网络状态影响。

## 使用

全局配置位于设置 → 歌词：选择默认来源、共享服务器与歌词缓存目录。中央歌词标题区仅保留一个无文字小图标，打开“歌词选项”弹窗；查找、导入、本曲来源与歌词偏移都在弹窗中。单曲来源可跟随全局或指定共享来源，临时检索选源不修改保存偏好。

顶栏“歌词”与音乐库、EQ平级。左侧播放信息可独立滚动，底部频谱固定保留完整高度；中央阅读歌词，右侧只保留封面与曲目信息。歌词选项弹窗分“查找歌词”和“本曲设置”，来源管理跳到全局设置。Esc先关闭弹窗，再返回音乐界面；音乐继续播放。

1. 播放歌曲，进入歌词页。页面先读取这首歌的本机缓存，打开页面或切歌不会自动联网搜索。
2. 点击歌词标题右侧的小图标，在弹窗“查找歌词”页点击“搜索”。打开弹窗不会自动查询。未指定单曲来源时默认查启用源，同分候选优先默认来源；明确指定单曲来源时默认只查该来源。可临时切换单源/多源，编辑曲名、歌手和可选专辑；各源分别显示结果/错误，候选标明来源。选择后获取、保存歌词并关闭弹窗。
3. 选中结果后，原文与可用翻译保存在本机；下次直接读缓存。也可导入UTF-8 LRC/TXT（最多96KiB），不改音乐文件或原始歌词文件。
4. LRC按行时间轴高亮，多时间戳和翻译可显示。纯文本只阅读，不模拟时间轴；暂不处理平台加密逐字歌词。点击有时间的行定位歌曲。
5. 手动滚动暂停跟随，按“回到当前行”恢复。弹窗“本曲设置”中可保存±30秒偏移，正值表示提前；保存偏移后保持弹窗打开。没有歌词时偏移控件禁用，正文不外露这些控件。LRC本身的有效整数offset标签也按正值提前解析。

## 来源适配与本机数据

`scripts/lyrics-library.mjs`独立负责搜索、候选、歌词获取与保存。网易云和QQ分别适配，没有下载或加载foobar插件二进制。手动`sourceId=auto`并行查询已启用来源、总时限20秒，单源失败不丢弃其他源结果；候选按各真实来源缓存，选用时不会把auto误作服务器ID。单曲显式来源覆盖与全局配置格式保持不变。来源错误、验证页、HTTP错误与空候选分别回报，不使用代理、登录Cookie或伪造地域标头。

歌词文件默认位于`MUSIC_DATA_DIR/lyrics/cache/<trackId的SHA-256>.json`，包含原文、可用翻译、来源和偏移；可通过Windows文件夹选择器指定缓存目录。更换后新内容写到新目录，旧缓存不复制、迁移或删除；读取按当前目录、最多16个历史目录、默认目录回退。全局默认源/目录在`MUSIC_DATA_DIR/lyrics/settings.json`，共享自定义来源在`MUSIC_DATA_DIR/lyrics/sources.json`，单曲来源覆盖在`MUSIC_DATA_DIR/lyrics/track-preferences/<hash>.json`，因此缓存换目录不改变单曲设置。删除某个共享服务器后，引用它的曲目暂用全局来源，并显示来源失效；原覆盖保留，用户可选新来源或恢复跟随。

这些本机数据不进入Git，不写音频标签。缓存/配置损坏时报告错误并保留文件；正常写入沿用串行原子替换。切歌/离页会取消过期在线请求，旧结果不能覆盖新曲显示。

自定义源支持HTTPS JSON GET接口，本机localhost/127.0.0.1/::1服务可用HTTP。默认搜索响应形如：

```json
{"results":[{"id":"song-id","title":"歌名","artist":"歌手","album":"专辑","duration":240}]}
```

歌词响应形如：

```json
{"lrc":"[00:01.00]歌词内容","translation":"[00:01.00]翻译内容"}
```

URL模板支持`{query}`、`{title}`、`{artist}`、`{album}`、`{id}`，各值独立URL编码。高级映射可指定点分字段路径，例如`{"results":"data.songs","id":"mid","title":"name","artist":"singer","album":"album.name","lrc":"data.lrc","translation":"data.translation"}`。艺人可为文本或带name的数组，时长按秒。最大12个自定义源；不执行用户脚本，不从候选中的任意地址下载文件。

## 频谱来自哪里

- WASAPI/ASIO PCM：`native/pcm-spectrum.h`收集真实PCM，在DSP、SRC和队列混音之后、主音量/淡变/量化之前取样。实时回调仅复制固定容量原子环形缓冲，FFT在status线程最多每100ms计算一次；不修改音乐样本。切曲/定位/暂停/停止重置历史，切轨或环形窗口覆盖时丢弃分析结果。
- 显示使用32个对数频段，范围20Hz至min(20kHz,Nyquist)，左右声道取较大能量，映射约-72至0dBFS。FFT窗口随采样率在4096至32768帧之间选择。这是视觉近似，不是精密频谱测量；取样精度不属于音乐输出处理精度链路。
- 浏览器兼容播放：歌词页可见时才接入当前歌曲的Web Audio Analyser，8192点FFT、32个对数频段；使用真实当前歌曲数据。分析不包含独立BGM或界面音效。
- 原生DSD/DoP直出暂无PCM频谱，不把DSD载荷或DoP容器当成音乐PCM分析；页面明确显示不可用。歌词进度仍可同步。

## foobar2000参考与接口资料

参考[foobar官方OpenLyrics页面](https://www.foobar2000.org/components/view/foo_openlyrics)及维护者的[来源适配器目录](https://github.com/jacquesh/foo_openlyrics/tree/main/src/sources)：采用独立来源、候选匹配、本地优先与可取消请求。OpenLyrics会按来源顺序尝试取得歌词；本项目为人工候选选择，手动多源搜索并行召回，再保留来源排序和分源状态。没有复制C++实现或加载其插件ABI；联网始终由用户点击搜索触发。

协议参考OpenLyrics的[网易](https://github.com/jacquesh/foo_openlyrics/blob/main/src/sources/netease.cpp)和[QQ](https://github.com/jacquesh/foo_openlyrics/blob/main/src/sources/qqmusic.cpp)适配器。2026-10-10公开演示“晴天 / 周杰伦”检查中，旧QQ Desktop POST返回服务码2001；smartbox HTTPS GET返回歌曲mid，既有歌词HTTPS GET返回retcode=0及非空定时歌词。网易云GET也返回code=200和可解析候选。这些是当时样例健康结果，不保证所有歌曲/地区或平台接口长期可用，不将无法访问当作“没有歌词”。

来源接口与歌词内容保留各自权利，不改授本项目MIT；缓存只留本机，本轮未分发歌词内容。没有新增npm/系统依赖、插件安装或全局环境变更。
