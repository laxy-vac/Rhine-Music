# 在线曲库

在线专辑使用独立列表和专辑架，不写入本地音乐索引；两者复用同一浏览/播放和三维场景。切换专辑架不打断当前播放，点击当前歌名可定位到对应来源。

## 使用

打开顶栏在线入口，选择来源/合集并搜索；加入候选后在“我的在线专辑”管理或切换到在线专辑架。来源设置与表单外观见[主题规范](THEME-PAGE.md)。

Future自有服务配置默认收起，展开后填写地址、账号和密码；Punk沿用默认展开。搜索结果可加入、定位或移除，移除在线元数据不删除本地音乐。

| 来源 | 行为 |
| --- | --- |
| Internet Archive | 搜索公开音频，可限定合集；选浏览器可播放格式，优先MP3 |
| Subsonic / OpenSubsonic | 用户主动配置的Navidrome、Jellyfin Subsonic插件、Airsonic等；不支持的浏览器格式可向服务请求转码 |

结果保留条目授权和来源链接，未标授权明确显示；受限借阅条目不加入/播放。播放器不提供商业音乐平台播放地址解析器。

## 数据与联网

在线曲库仅在用户搜索、加入或播放时访问远程来源，不仅因启动而主动查询远程库。加入保存专辑元数据快照，不下载或缓存在线音频；离线可查看快照，播放需要来源可达。

数据与连接配置保存在应用数据目录的`online.json`，实际目录见[本地开发](LOCAL-DEVELOPMENT.md)，不在源码中。密码在本机以明文保存，API不返回密码，只返回已保存状态；Subsonic认证使用盐值令牌。可为播放器单独配置只读账号。

## 接口与请求边界

- 来源、列表、搜索和管理使用`/api/online/*`，音频/封面由本机服务转发`/api/online/audio/<id>`、`/api/online/artwork/<id>`，支持Range。
- 服务只监听127.0.0.1，保留Host/Origin校验，写入接口只接受JSON；浏览器不直接带账号访问远程站点。
- Internet Archive仅允许https的archive.org及其子域；自有服务只允许用户配置地址。重定向逐跳检查，不能借转发访问任意目标。
- 音频与封面响应按许可的MIME类型处理，非音频/图片或越界目标拒绝，不转发网页内容。

实现见[scripts/online-sources.mjs](../scripts/online-sources.mjs)及[music-server.mjs](../scripts/music-server.mjs)。`scripts/check-online-sources.mjs`使用本机假服务验证协议、白名单、Range和保存；它不访问真实互联网，也不代表个人服务器或硬件性能验收。
