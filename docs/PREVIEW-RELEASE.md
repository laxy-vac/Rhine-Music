# 品尝版安装与交付

既有交付快照版本为`0.3.1-preview.1`，不是当前开发源码的自动更新包。当前功能见[PROJECT-STATUS](PROJECT-STATUS.md)，后续优化见[OPTIMIZATION-BASELINE](OPTIMIZATION-BASELINE.md)。本说明保留安装、存储和交付方式，不再用已结束的架构阶段描述产品现状。

## 安装与首次使用

安装器为`Rhine-Music-0.3.1-preview.1-Setup.exe`，校验值随`.sha256`提供。选择普通用户可写的独立目录，默认在安装器旁；未知非空目录拒绝覆盖，已有应用标记的目录可用于重新安装。

安装后自行运行`Rhine Music Preview.exe`。安装器不提权、不改ACL；目录不可写则拒绝，不回退AppData。应用不自动扫描曲库，首次使用由用户在设置中选择音乐目录并主动扫描。

安装器未签名。安装器生成、实际安装、窗口使用与音频设备能力是不同验证范围；旧包不因当前源码通过检查而获得新的验证结论。

## 数据与卸载

- 应用文件在安装目录的`resources/app`，运行时许可随包保留。
- 数据在`<安装目录>/data`，主题/EQ预设在`<安装目录>/presets`；源码验证profile与它们分开。
- 个人盒体库Future/Punk独立，原音乐与外部歌词文件不进入安装载荷；不自动导入作者的配置或曲库。
- 坏预设或启动后被外部修改的文件拒绝自动覆盖。用户选择的外部目录不因安装或卸载迁移。
- 运行`Uninstall.exe`卸载。默认保留data/presets，只有用户明确勾选才清除安装目录内这两处；外部音乐不在删除清单，未知文件不递归清扫。
- 实际安装会为当前用户登记卸载入口（HKCU），不改文件关联、服务、启动项、系统PATH或ACL。编译安装器不等于运行安装器。

## 构建与导出

| 入口 | 用途 |
| --- | --- |
| `npm test` | 有限离线合成检查 |
| `npm run build:preview` | 源码界面构建 |
| `npm run desktop` / `启动源码验证.cmd` | 源码验证窗口 |
| `npm run package:preview` / `打包品尝版.cmd` | 使用已准备工具生成安装器 |
| `npm run export:source` | 生成不含环境与个人数据的交付ZIP |

所有命令在仓库根运行；现有工具及完整构建见[本地开发](LOCAL-DEVELOPMENT.md)。普通入口不会自动安装依赖或下载缺项。打包校验源码和组件指纹，不能用旧产物冒充新版。

源码ZIP不包含`.git`、依赖、工具、构建、个人数据或机器验证记录；它是交付物，不用于另建第二份日常开发仓库。当前开发与用户自行发布共用main，助手不自动推送或发布。
