# 音乐核心实施基线（历史方案）

日期：2026-10-10。本文保留当时的设计依据，不是当前实施清单或新任务授权。当前架构与限制见 [AUDIO-CORE-IMPLEMENTATION](AUDIO-CORE-IMPLEMENTATION.md)，整体进度/验收见 [PROJECT-STATUS](PROJECT-STATUS.md)。后来纯输出临时独占与官方CLAP方案以现行文档/代码为准。

## 结构

专项审查后的执行约束：PCM 解码与 DSP 后提交之间各有预分配 SPSC，RAW/DoP 独立字节队列；生产者负责读取、处理及动态状态，提交回调仅有限消费/淡变/量化/打包。每个队列单生产者、单消费者，以 release/acquire 发布所有权，只有双方停止后可 reset。控制邮箱由调用方持有命令生命周期，输出 worker 不分配/销毁命令任务。阻塞 I/O 可取消、退出有截止时间，无法安全静止时关闭隔离原生进程，不释放仍在使用的内存。ASIO/WASAPI 的打包对齐、容器位数与有效位必须显式区分。参见 [修复报告](AUDIO-CHAIN-FIX-REPORT-2026-10-10.md)。

界面 → 应用服务 → 原生播放核心 → 可替换组件适配层。适配器随源码构建，不提供任意二进制插件加载。处理器报告格式、运算精度、延迟、帧计数和错误；通用设置不依赖具体库名称。

2026-10-10最终选型：FLAC/Ogg FLAC使用直接libFLAC接口，其他通用PCM音乐使用FFmpeg；不保留BASS PCM解码后端或自动回退。BASS基础库/BASSDSD/BASSASIO仅维持独立DSD解码/DoP及ASIO输出用途，不能混称PCM解码选择。原文件解码由预取线程执行并通过固定double环形缓冲交给播放回调；声道/率中途改变、无法精确定位或无法支持的容器明确报错。Sony内部渐进float32 WAV用独立缓存读取器，不是BASS回退。解码器内部运算未知、解码样本格式及适配后的Float64分别报告。

重采样支持r8brain、SoX/libsoxr与快速线性插值。SoX显式使用Float64交错I/O与双精度运算，可选HQ/VHQ和85–99.5%的通带比例；仅实际变率时运行。保持既有r8brain默认偏好，旧备份缺SoX参数时补默认VHQ/97%，不隐式改变用户保存的其他设置。

PCM 当前实现顺序：解码 → 可选 Sony 声音增强 → ReplayGain / 音调 / EQ → 必要输出重采样 → 连续队列/混音 → 音乐音量 → 量化/抖动 → 设备提交。WASAPI 共享模式在提交后另经过 Windows 系统混音。Sony 处理仍作为独立 PCM 模块，其 Float32 文件边界必须如实显示。原生 DSD/DoP 不进入 PCM 处理。

DSEE 与输出重采样独立设置：DSEE 在支持的44.1/48kHz PCM输入上进行增强与四倍升频，输出176.4/192kHz。输出采样率使用“跟随处理结果 / 自动匹配允许列表 / 指定采样率”，跟随保留前段处理率，自动匹配处理后输入率，指定使用用户目标率。此名称调整不改变既有设置值或算法。DSEE节点与输出重采样分别显示实际输入/输出率，Windows共享混音独立显示系统报告的混音格式，不称为DAC内部精度或硬件最终格式。未知输入率不能按四倍关系倒推。

## 精度

Float64是实验性优先模式，长期目标是完整双精度链路。各阶段可回退Float32并报告理由。源文件位深、解码输出格式、内部运算精度和设备输出格式分别展示；转换为Float64不恢复已丢失精度。只知道输出格式时不猜测解码器内部精度。

## EQ和预设

- Poweramp图形/参数JSON分别解释；已确认样本的前两条为独立低音/高音描述，后续才是EQ频段。
- 参数type 0/1/2/3/4/5为低通/高通/带通/峰值/低架/高架；channels 0/1/2为双声道/左/右。图形type2按图形提升解释，q=0不是有效数值Q。
- 图形5–32段，默认10段，支持常用频率布局及自定义首末频率。带宽按中心频率间距估算，0.5–2倍可调且只在图形模式显示。切段采用频率Hz上的增益分段线性插值并保留撤销。
- 参数频段可编辑类型、声道、频率、增益、Q、启停及锁定。实际参数保留精度，显示可舍入。
- 音调独立于上方EQ，开关决定旋钮增益是否参与，关闭不清值，0dB等价于不处理。导入不隐式更改本地音调开关。压限器不实现、不自动启用。
- 本地保存工作状态、命名预设、音调状态及设备配置。导入原件不改写。未知类型/无效参数明确拒绝，不静默丢弃。
- 所有旋钮/滑块允许数值输入，Enter提交/Esc取消，明确单位、范围及错误。

## 播放和输出

2026-10-10 纯输出交互更新：比特一致性开关直接启用 Direct，WASAPI 仅在实际 open 中自动选择独占，保存偏好保留，关闭后恢复。解码帧直接读入传输块，跳过 DSP 调用；输出端做必要整数格式打包与样本一致性校验。前端只显示等待/一致/不一致，算法精度区以实际阶段表呈现，解释可折叠。此规则替代下方历史“必须手工独占、不自动切换”的交互约定，其他设备/格式不兼容仍禁止静默回退。

预加载下一曲实现真正连续帧提交；交叉渐变用两条流在同一输出率混音。自动/手动过渡、暂停/停止/定位淡变分别管理。格式不兼容明确回报，不假称无间隙。

WASAPI设备和共享/独占分别保存；自动/手动选择输出率和样本格式，缓冲与重新配置等待分开。指定设备不可用或占用时不偷偷换设备。停止/结束/错误释放输出。

PCM原样输出不允许DSP/RG/增益/SRC/混音/抖动，不能只因独占而声称位级一致。DoP保持有效24位整数载荷、精确载波率和连续标记；不做浮点处理。状态区分DSD内容和DoP容器。

PCM比特一致性以运行副本暂停冲突处理并保留用户偏好，关闭恢复。资格取实际libFLAC/FFmpeg无损整数解码结果及16/24/32有效位，不取标签猜测；FLAC32也可进入Double而不先经过Float32。保留整数有效样本值，设备容器可无损扩展并以零填充。独占/ASIO整数输出与源率分别验证；不自动更换设备/模式，不静默回退。提交边界做PCM打包前后逐样本数值比较并报告数量，出错停止；不能将本地检查宣称为解码器正确性或DAC端的比特认证。暂不支持此模式的预载/混音或DSD转换。

## 本地管理和验收

工具和缓存在.tools，源码组件在vendor/audio并记录固定版本、许可、来源与哈希。运行继续使用源码验证Electron，不最终打包。提交按功能分组，回滚采用revert保留历史；不执行reset --hard，不推送远端。

隔离验收覆盖导入/保存、滤波响应、精度边界、重采样尾部、帧连续性、量化和会话顺序。真实设备与用户音乐体验单独验收，不借以前结果声明新功能通过。
